# Community Apps submission

The current submission portal is https://ca.unraid.net/submit/new.
[Submission help](https://ca.unraid.net/submit/help) is the authoritative flow.

This repository contains root MIT `LICENSE`, nonempty `ca_profile.xml`, an
original icon and a version 2 Docker template under `templates/`. Support points
to project issues, which the
[public field reference](https://ca.unraid.net/submit/help/xml-field-reference)
accepts. A dedicated Unraid forum support thread can be added later.

1. Verify the image can be pulled anonymously, the raw XML/icon links resolve,
   and the install path has been tested with Docker Manager.
2. Sign in with the maintainer's existing Unraid account.
3. Enter `https://github.com/nullifyr/excalidraw-live-unraid` and **Validate**.
4. Run **Scan**, review the generated application preview, and fix any findings.
5. Submit for review with owner approval for any newly presented terms.
6. Record the submission ID/status. Verify catalog inclusion independently.

The portal says submission agrees to
[Unraid's policies](https://unraid.net/policies). An agent must not accept newly
presented terms or create account credentials without the owner's approval.
Publishing this repository and its image does not establish portal submission,
moderation approval or catalog availability.
